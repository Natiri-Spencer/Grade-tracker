# Grade Tracking System

A reliable application for evaluating student performance from structured CSV data.  
It ensures smooth handling of missing or invalid inputs, applies logical rules to compute results, and produces clear reports that can be exported to JSON.

---

## ✨ Features
- **CSV Data Ingestion**: Reads structured grade data directly from CSV files.  
- **Error Handling**: Gracefully manages missing or invalid inputs without crashing.  
- **Result Computation**: Applies logical rules to calculate student outcomes and performance metrics.  
- **Report Generation**: Formats results into a clear, human‑readable report.  
- **Data Export**: Saves processed results into JSON format for integration or further analysis.  

---

## 🛠 Tech Stack
- **Python**  
- **pandas / csv** (for data handling)  
- **JSON** (for exporting results)
